# AGENTS.md

Read **[CLAUDE.md](CLAUDE.md)** in this directory. It is the briefing for this
plugin and it is not duplicated here: what the plugin does, what it stores, what
couples it to its siblings, and the things that look wrong and are deliberate.

Then read **[`../_standards/STANDARDS.md`](../_standards/STANDARDS.md)**, the
contract all nineteen plugins in this collection are held to. Where a plugin's
own file and the standard disagree, the standard wins.

This file exists so that a tool looking for `AGENTS.md` finds its way to the
real guidance. Everything worth saying is kept in one place, because guidance
copied into two files becomes two files that disagree.
